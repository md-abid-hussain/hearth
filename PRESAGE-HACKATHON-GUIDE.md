# Presage SmartSpectra SDK Challenge — Hackathon Guide

**Source:** [Challenge page](https://dev.to/challenges/presage-2026-11-04) · [Presage contest rules](https://dev.to/page/presage-2026-11-04-contest-rules) · [General official rules](https://dev.to/page/official-hackathon-rules)

**Prompt:** Build an experience with the Presage SmartSpectra SDK that responds to real-time human signals captured through a camera (pulse, breathing rate, HRV, expressions, etc.).

**Total prizes:** $3,000 across **10 winners**

| Milestone | Date |

| Submissions due | November 22, 2026 at **11:59 PM PST** |
| Winners announced | December 10, 2026 |

## Tracks / prize categories

You do **not** need to enter a prize category to be eligible for an overall winner spot. One submission can be eligible for overall **and** both categories at once, but **each submission can win only once**.

| Track | What it is | Winners | Prize each |
| --- | --- | --- | --- |
| **Best Overall Human-Sensing Experience** | Working experience that responds meaningfully to live camera-captured human signals via SmartSpectra | **4** | $300 USD + DEV++ + winner badge |
| **Most Creative or Delightful Use** | Most original, playful, or unexpected use of SmartSpectra | **3** | $300 USD + DEV++ + winner badge |
| **Best Thoughtful Real-World Use** | Clear real-world need with strong usability, consent, and responsible data handling | **3** | $300 USD + DEV++ + winner badge |

**Also:** Valid/qualified participants get a **completion badge** on their DEV profile.

**Pro tip from organizers:** Category winners are drawn from a smaller pool, so odds can be higher if you fit a category — note which one(s) in the Prize Categories section of the template.

---

## Judging criteria

All 10 winners are judged on:

1. **Use of underlying technology**
2. **Usability and user experience**
3. **Originality and creativity**

**Tie-breaker:** Highest number of positive reactions on the DEV submission post.

**Verification:** Judges check your **public code repo** and **demo video** for a real SmartSpectra SDK integration and at least one live Presage signal. Missing that can mean disqualification.

## Am I eligible?

You are eligible if **all** of the following are true:

- You are **18+** (or legal age of majority where you live) and can form a binding contract
- You are a **DEV Member** (registered, active account in good standing)
- You have an **active email** and **internet access** during the entry period
- You are **not** a resident of (or an entity from) these jurisdictions:  
  Afghanistan, Belarus, Central African Republic, Cuba, Equatorial Guinea, Iran, Iraq, Kosovo, Libya, Myanmar (Burma), North Korea, Russia, South Sudan, Sudan, Syria, Tanzania, Venezuela, Yemen  
  (also ineligible if subject to U.S. export controls / restricted party lists)
- You are **not** an employee (or household/immediate family) of Major League Hacking PBC Inc. / affiliates / coordinating agencies during the entry period
- Contest is **not void** where you live (void where prohibited/restricted by law)

**This challenge also requires:**

- **Individual only** — team submissions are **not** allowed
- **One entry per person** (if you submit more than one, only the **first** counts)
- Work started **during** the Entry Period (not before Nov 4, 2026) — per general official rules

> Self-check: If you are 18+, have a DEV account, are not in a listed restricted country, and will submit alone before the deadline, you are likely eligible. Confirm against [official rules](https://dev.to/page/official-hackathon-rules) for your specific situation.

## What every submission must include

1. **DEV post** using the [submission template](https://dev.to/challenges/presage-2026-11-04) and tag **`#presagechallenge`**
2. **Functional app** integrating the **SmartSpectra SDK** with **at least one live** Presage signal (pulse, breathing rate, HRV, expressions, etc.)
3. **Public code repository** + **setup instructions**
4. **Demo video** showing live signal(s) in action (public hosting of the app is optional)
5. **Consent and Data Handling** section — camera consent, storage/sharing/retention/deletion, SDK telemetry, optional AI use  
   → Submissions without this may be treated as **incomplete**

If the app needs login, provide **test credentials** and/or clear testing instructions for judges.

**Optional but encouraged:** Embed a public Agent Session (Claude Code, Gemini CLI, Codex, GitHub Copilot CLI, or Pi). Make the session **public** or judges can’t open it; scrub keys/secrets first.

## What can invalidate / disqualify your entry

### Hard disqualifiers / not allowed

| Issue | Effect |
| --- | --- |
| **Diagnosis or treatment claims**, medical decision-making | Disqualified |
| **Covert or non-consensual monitoring** | Disqualified |
| **No functional SmartSpectra SDK integration** / no live Presage signal shown in code + demo | May be disqualified |
| **Team submission** | Not allowed |
| **Multiple entries** | Only first entry judged |
| **Under 18** / ineligible geography / not a DEV member | Ineligible |
| **Plagiarism** | Not prize-eligible; incidental plagiarism → challenge DQ; egregious → DEV suspension |
| **Non-English submission** | Completion badge OK; **not eligible for prizes** |
| **Trivial remix** of prior/OSS work without significant changes | Submission may be invalid |
| **Prior work started before Entry Period** | Violates general official rules warranty |
| **Missing required elements** (DEV post, tag, repo, setup, demo, consent section) | Incomplete / may be DQ’d |
| **IP infringement**, illegal/obscene/pornographic/etc. content | May be disqualified |
| **Violates employer policies** | Deemed ineligible |
| **Tampering / disruptive conduct** | Sponsor may disqualify |

### Credit / originality notes

- Open source and building on prior ideas is encouraged, but changes must be **significant enough** to be valid
- Any non-generic, non-trivial prior work (including OSS) **must be credited**
- AI use is **allowed** if all other rules are followed

### Prize claim pitfalls (after winning)

- Must respond to winner email; may need affidavit + tax info (e.g. W-9 / SSN / tax ID) within **7 business days** of first notification
- Failure → prize may be **forfeited**
